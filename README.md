# Sobre o projeto

Chatbox Mal Humorado é uma aplicação backend, ela consiste em um bot que responde dúvidas com um tom de sarcasmo, estilo professor ranzinza. Ela utiliza a API do Google Gemini para responder as dúvidas.  

O objetivo dessa aplicação foi para eu compreender melhor como funciona a integração de uma API com um projeto prático, muito boa a experiência.
